1. Terminology

These are the words this SDK uses. Everything you write is a post on a customer’s shared or private board.

externalCustomerId

Your CRM id for the customer, for example CRM-1001.

BoardType

Where the post lives for that customer.

BoardType::Shared
BoardType::Private

Post

One record you create. It has a title, notes, and files.

Note and file

Text and attachments on a post. FileUpload is an in-memory file (bytes, name, type).

2. Prerequisites

  • PHP 8.2+ and Composer
  • Server-side only (not the browser)
  • An API key: xbk_test_… or xbk_live_…
  • Gateway base URL (origin only):
    • Dev: https://api.dev.sidekiq.com
    • Prod: https://api.xboard.com
  • The customer already exists in xBoard. You will identify them with externalCustomerId.

3. Setup

Install

composer require xboard/php
use XBoard\BoardType;
use XBoard\FileUpload;
use XBoard\XBoard;

$client = new XBoard([
    'apiKey'  => getenv('XBOARD_API_KEY'),
    'baseUrl' => getenv('XBOARD_BASE_URL'),
]);
$posts = $client->customers->posts(); // handle only — does not list or fetch posts

Not a list $client->customers->posts() is a resource handle. It does not list posts and does not call the API. Create, compose, and list always take externalCustomerId and boardType. There is no account-wide post list.

4. Write a post

One chain. Call order is the content order. setTitle() at most once. create() always makes a new post. Each step is its own HTTP call; the first error stops the sequence, and whatever already landed stays.

$post = $posts
    ->compose('CRM-1001', BoardType::Shared)
    ->setTitle('Site visit')
    ->addNote('Arrived on site.')
    ->addFile(new FileUpload("hello\n", 'hello.txt', 'text/plain'))
    ->addNote('Photos to follow.')
    ->create();

To add more later, compose on that same $post. update() never creates. Title replaces; notes and files only append.

$post->compose()
    ->setTitle('Site visit — complete')
    ->addNote('Customer signed off.')
    ->addFile(new FileUpload("signed\n", 'signoff.txt', 'text/plain'))
    ->update();

If you only have a post id (for example from storage), load it first, then use the same compose chain:

$post = $posts->get($postId);
$post->compose()
    ->addNote('Follow-up.')
    ->update();

5. Read it back

List is scoped to one customer and board. Pass both arguments every time. There is no account-wide post list. $posts->get($postId) loads one post by id; it is not a list.

$listed = $posts->list('CRM-1001', BoardType::Shared); // required: customer + board
$post   = $listed[0]; // first post for that customer and board
$notes  = $post->notes()->list(); // notes and files on that post

6. Errors

Failed HTTP calls throw XBoardError (and subclasses). Bad arguments throw \InvalidArgumentException.

use XBoard\Errors\XBoardError;

try {
    $posts
        ->compose('CRM-1001', BoardType::Shared)
        ->setTitle('Kickoff')
        ->create();
} catch (XBoardError $err) {
    // $err->statusCode, $err->errorCode, $err->requestId
}
